# 動作確認チェックリスト

実サーバーで確認する。チェックは各項目を上から順に実施する。

## 起動・環境

- [ ] `direnv allow` 後に `bun --version` が表示される
- [ ] `bun install` が成功する
- [ ] `bun run check` がエラーなしで終わる
- [ ] `bun test` が成功する
- [ ] `bun run build` が成功する
- [ ] `.env` に `DISCORD_TOKEN` を設定して `bun run start` で起動し、ログに `Logged in as ...` が出る
- [ ] 起動後に `/meetup` が Discord に入力候補として表示される
- [ ] 一般メンバーが `/meetup init` を実行すると拒否される
- [ ] 管理者が `/meetup init` を実行すると `MeetUp` カテゴリ、`オフ会募集` フォーラム、`招待` チャンネルが作成される
- [ ] `オフ会募集` がカテゴリ最上部、`招待` が 2 番目にある
- [ ] init 前に `/meetup create` を実行すると、init を促すメッセージが返る
- [ ] init を再実行してもチャンネルが重複しない

## Public オフ会（主催者承認）

- [ ] `/meetup create` で `mode:PUBLIC`、`approval:HOST` のオフ会を作成できる
- [ ] 非公開の専用チャンネルが作られ、主催者だけが閲覧できる
- [ ] `オフ会募集` に募集投稿が作られ、参加申請ボタンが付いている
- [ ] `/meetup list` で一般メンバーには Public だけが表示され、Private は招待・申請済みの人にだけ表示される
- [ ] スケジュールイベント連携を有効にすると Discord イベントが作成される
- [ ] 別メンバーが募集投稿の「参加申請」を押せる
- [ ] 申請通知が専用チャンネルに届き、主催者が「承認」できる
- [ ] 承認されたメンバーが専用チャンネルを閲覧・発言できる
- [ ] 承認されたメンバーの DM または通知で参加確定が伝わる
- [ ] 却下したメンバーは専用チャンネルを閲覧できない
- [ ] 辞退・キャンセルしたメンバーは専用チャンネルを閲覧できない（参加キャンセル時）
- [ ] 定員に達した後も参加申請自体は受け付けられる

## Public オフ会（参加者投票）

- [ ] `approval:VOTE` と必要票数を指定して作成できる
- [ ] 参加申請に対して参加確定者が賛成票を押せる
- [ ] 投票制の参加申請でも主催者が「却下」できる
- [ ] 同じ人が二重投票できない
- [ ] 必要票数に到達した時点で自動的に承認される
- [ ] 承認後に専用チャンネルへ追加される

## Private オフ会

- [ ] `/meetup create` で `mode:PRIVATE` のオフ会を作成でき、募集フォーラムに投稿されない
- [ ] 主催者が `/meetup invite` でメンバーを招待でき、DM に招待ボタンが届く
- [ ] DM の「参加する」で参加確定し、専用チャンネルを閲覧できる
- [ ] DM の「参加しない」で辞退状態になる
- [ ] 辞退したユーザーが `/meetup apply` で再申請でき、主催者が承認できる
- [ ] 招待されていないユーザーは Private オフ会へ申請できない
- [ ] 参加確定者が `/meetup invite` を使うと、主催者承認待ちになる
- [ ] 主催者が承認すると招待 DM が送られる

## DM 失敗時のフォールバック

- [ ] DM を拒否しているユーザーを招待すると、`招待` チャンネルにプライベートスレッドが作られる
- [ ] スレッドには招待対象者と Bot だけが参加している
- [ ] スレッド内の「参加する」「参加しない」で状態が変わる
- [ ] 回答後に一時スレッドが削除される
- [ ] DM もスレッドも失敗した場合、主催者側へ招待失敗が通知される
- [ ] 招待送信に失敗した対象は「招待中」のまま残らず、再招待できる

## 集合情報・リマインド

- [ ] `/meetup edit` でオフ会名・定員・開催日時を変更でき、開催日時を変えるとリマインド時刻も更新される
- [ ] `/meetup edit` で開催日時を変えたとき、連携スケジュールイベントの開始日時も更新される
- [ ] `/meetup edit` で名前・開催日時を変えたとき、Public の募集投稿（スレッド名・埋め込み）も更新される
- [ ] `/meetup info` で集合時間・集合場所を変更でき、参加者へ通知される
- [ ] 集合場所は参加確定者だけが閲覧できる（未確定者・一般メンバーには見えない）
- [ ] オフ会作成時点でリマインド（24 時間前・3 時間前・30 分前）が自動登録される
- [ ] 開催 24 時間前・3 時間前・30 分前に専用チャンネルで参加確定者がメンションされる
- [ ] キャンセルしたメンバーはリマインドのメンション対象にならない
- [ ] アーカイブ後・中止後はリマインドが送られない
- [ ] `/meetup remind` で任意のタイミングに通知できる

## アーカイブ・中止

- [ ] `/meetup archive` が確認ボタンを出し、実行すると状態が ARCHIVED になる
- [ ] チャンネル名の先頭に `archive-` が付く
- [ ] 主催者のチャンネル管理権限が外れる（サーバー管理者権限は別扱い）
- [ ] アーカイブ後も参加確定者は閲覧・発言できる
- [ ] アーカイブ後は新規申請・招待・リマインドが止まる
- [ ] アーカイブ時に連携スケジュールイベントが「キャンセル済み」になる
- [ ] `/meetup cancel` で状態が CANCELLED になり、参加者へ通知される
- [ ] 専用チャンネル内で `meetup` を省略して `/meetup cancel` を実行すると、その専用チャンネルのオフ会が対象になる
- [ ] 中止後は新規申請・招待・リマインドが止まる
- [ ] 中止後、連携スケジュールイベントが「キャンセル済み」になり、公開履歴が残る

## チャンネル削除復旧

- [ ] 専用チャンネルを Discord 上で直接削除すると、Bot が再作成する
- [ ] 再作成後に参加確定者の権限が再設定される
- [ ] 主催者に「中止する / ACTIVE を維持する」の確認が出る
- [ ] 「中止する」で CANCELLED になる
- [ ] 「ACTIVE を維持する」で状態が維持される

## カテゴリ上限

- [ ] カテゴリ内のチャンネル数が 50 に達すると、`MeetUp-2` 以降が作成される
- [ ] 移動対象はアーカイブ済みチャンネルが優先される
- [ ] `オフ会募集` と `招待` は元のカテゴリに残る
- [ ] 移動後もチャンネル名・履歴・参加者権限が維持される
- [ ] 承認・キャンセルなどで権限を同期しても、管理者が追加したロール単位の権限上書きは消えない

## 権限

- [ ] 主催者以外の一般メンバーは専用チャンネルを閲覧できない
- [ ] 主催者・共同主催者が参加承認・却下・招待・集合情報変更・アーカイブを実行できる
- [ ] 参加確定者が参加キャンセル・招待申請・投票を実行できる
- [ ] 主催者は自分自身の参加キャンセルができない
- [ ] 主催者変更後、旧主催者の管理権限が外れる
