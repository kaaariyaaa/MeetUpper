# コマンド一覧

すべて `/meetupper` のサブコマンドとして提供する。スラッシュコマンドの引数は対象MeetUpの指定（`[meetup]`）だけであり、ユーザー・操作種別・各設定値はコマンド引数では受け取らない。作成・編集・招待・退出などの操作は、すべて表示されるボタン・セレクトメニュー・モーダルで行う。

`[meetup]` は任意。MeetUpの専用チャンネル（またはその中のスレッド）や `meetup募集` の募集スレッド内で実行すると、そのMeetUpを対象として省略できる。文脈がない場所で省略した場合は、対象を選ぶ一覧を表示する。

## コマンドと画面

| コマンド | 実行できる人 | 表示される画面・操作 |
| --- | --- | --- |
| `/meetupper init` | サーバー管理者 | セットアップ内容の確認パネル → 「実行する」で `MeetUp` カテゴリ・`meetup募集` フォーラム・`招待` チャンネルを作成する（既存なら再利用） |
| `/meetupper create` | サーバーメンバー全員 | 4項目の作成モーダル → 作成結果パネル（MeetUpを開く / 編集 / リマインダー） |
| `/meetupper list` | メンバー全員 | ダッシュボード。募集中 / 参加中 / 管理中を切り替え、MeetUpを選択して詳細へ |
| `/meetupper show [meetup]` | 閲覧権限のある人 | 詳細パネル。権限に応じた操作ボタンを表示する |
| `/meetupper apply [meetup]` | メンバー全員（Private は招待・再申請可能な人） | 参加確認パネル。引数もチャンネル文脈もなければ参加可能なMeetUpの一覧 |
| `/meetupper invite [meetup]` | 主催者・共同主催者・参加確定者 | ユーザー選択 → 確認 → 招待DM（失敗時は招待スレッド）。参加確定者の場合は主催者承認を経る |
| `/meetupper members [meetup]` | 主催者・共同主催者 | 参加者と状態の一覧パネル（ページ切り替え） |
| `/meetupper leave [meetup]` | 参加確定者本人（主催者・共同主催者は不可） | 参加キャンセルの確認パネル。文脈がなければ参加中のMeetUp一覧 |
| `/meetupper kick [meetup]` | 主催者・共同主催者 | 参加確定者の選択 → 確認 → 退出（専用チャンネルの権限解除と通知） |
| `/meetupper cohost [meetup]` | 主催者 | 共同主催者の追加（ユーザー選択）・削除（一覧から選択） |
| `/meetupper host [meetup]` | 主催者 | 新しい主催者のユーザー選択 → 確認 |
| `/meetupper edit [meetup]` | 主催者・共同主催者 | 設定ハブ。各項目を下書きし、「保存」で一括反映する |
| `/meetupper info [meetup]` | 主催者・共同主催者 | 集合時間・集合場所の入力モーダル → 保存して参加者へ通知 |
| `/meetupper archive [meetup]` | 主催者・共同主催者 | アーカイブの確認パネル（ACTIVE と中止済みが対象） |
| `/meetupper cancel [meetup]` | 主催者・共同主催者 | 中止の確認パネル |
| `/meetupper reminder [meetup]` | 主催者・共同主催者 | 既存のリマインダー設定画面 |

## 共通の画面ルール

- 応答はすべて ephemeral（実行者だけに表示）で、日本語で表示する。
- 複数ステップの画面は `src/core/ui.ts` のセッションに状態を保持する（15分TTL、実行者・ギルドに紐付け）。
- ボタン・セレクトメニュー・モーダルの操作ごとに、実行者・ギルド・MeetUpの状態・権限を再確認する。
- 他人のセッション、期限切れのセッション、対象MeetUpがアーカイブ済み・中止済みなどで操作できない場合は、その旨を表示してコマンドの再実行を促す。
- 破壊的操作（退出・キック・主催者変更・中止・アーカイブ・招待送信）は、確認ボタンを押した時点で実行する。確認前には状態を変更しない。
- 操作完了後は結果を同じ ephemeral 画面に表示し、詳細・編集などへ移動できるボタンを残す。

## 作成モーダル

`/meetupper create` は1つのモーダルを開く。入力するのは次の4項目だけ。

- 公開モード（Public / Private）
- 参加方法（直参加 / 主催者承認 / 参加者投票。Private は主催者承認固定）
- MeetUp名
- 開催日時（`YYYY-MM-DD HH:mm`、`DEFAULT_TIMEZONE` 基準）

作成時に固定される初期値:

- 定員なし（0）
- 説明なし
- 集合時間・集合場所なし
- 共同主催者なし
- イベント連携OFF
- 自動リマインダーON（1日前・3時間前・30分前）
- 参加者投票の必要票数は1（作成後に `/meetupper edit` で変更）

作成後は結果パネルに「MeetUpを開く」「編集」「リマインダー」を表示する。MeetUp名・説明・定員・集合情報・共同主催者・イベント連携は、作成後に `/meetupper edit` で設定する。

## 一覧ダッシュボード

`/meetupper list` は「募集中」「参加中」「管理中」の3つの表示を切り替えられる。

- 募集中: 自分が閲覧・参加申請できるACTIVEなMeetUp
- 参加中: 自分が参加確定しているMeetUp
- 管理中: 自分が主催者または共同主催者のMeetUp

一覧からMeetUpを選ぶと詳細パネルへ移動する。Private MeetUpは、招待・申請・参加の記録がある人だけに表示する。表示できるMeetUpがない場合は、その旨と作成への導線を表示する。

## 詳細・参加者パネル

`/meetupper show` の詳細パネルには、MeetUp名・公開モード・状態・開催日時・参加状況などを表示する。操作ボタンは実行者とMeetUpの状態に応じて出し分ける。

- 一般メンバー: 参加（参加可能な場合）、一覧へ戻る
- 参加確定者: 退出、招待
- 主催者・共同主催者: 編集、参加者一覧、招待、キック、集合情報、アーカイブ、中止、リマインダー
- 主催者のみ: 共同主催者の追加・削除、主催者変更

`/meetupper members` は参加者と状態を一覧表示し、「前へ」「次へ」でページを切り替える。参加者一覧は主催者・共同主催者だけが開ける。

## ユーザーを選ぶ操作

- 招待: ユーザーセレクトで対象を選び、確認パネルを経て招待を送る。参加確定者が実行した場合は主催者・共同主催者の承認待ちになる。
- キック: 参加確定者だけを選択肢に出す。確認パネルで「退出させる」を押すと、専用チャンネルの権限を解除して参加者へ通知する。退出させられた人は再申請できない。
- 共同主催者の追加: ユーザーセレクトで追加する。削除は現在の共同主催者の一覧から選ぶ。
- 主催者変更: 新しい主催者をユーザーセレクトで選び、確認パネルを経て変更する。旧主催者の権限は新主催者へ移す。

いずれも選択しただけでは確定せず、確認ボタンで実行する。対象がサーバー外・Bot・自分自身など操作できない相手の場合はエラーを表示する。

## 編集ハブ（保存式）

`/meetupper edit` は設定ハブを開く。変更はセッション内の下書きとして保持し、「保存」を押した時点でまとめて反映する。「キャンセル」で下書きを破棄する。

編集できる項目:

- 基本情報: 名前・説明・定員・開催日時
- 参加方法: 直参加 / 主催者承認 / 参加者投票（必要票数）
- 集合情報: 集合時間・集合場所
- イベント連携: ON/OFF（Public のみ）
- 共同主催者・主催者変更への導線
- リマインダー設定への導線

日時を変更した場合は、リマインダーの通知予定を再計算し、連携中のスケジュールイベントと Public の募集投稿も更新する。保存後は参加者への通知など従来の処理を行う。Private の参加方法は主催者承認固定で、参加者投票には変更できない。

## 集合情報

`/meetupper info` は集合時間・集合場所を入力するモーダルを開く。集合時間を空欄にすると現在の値を維持し、集合場所を空欄にすると削除する。保存すると専用チャンネルで参加者へ通知する。集合場所は参加確定者と主催者側だけが閲覧できる。アーカイブ後は変更できない。

## 退出・アーカイブ・中止・初期化の確認

- 退出 (`/meetupper leave`): 参加キャンセルの確認パネルを表示し、「キャンセルする」で確定する。主催者・共同主催者は自分では退出できない。
- アーカイブ (`/meetupper archive`): 対象と影響を表示し、確認後にARCHIVEDへ変更する。Public MeetUpの募集スレッドはロックして閉じ、返信や新規投稿を受け付けない。アーカイブ済みのMeetUpには実行できない。
- 中止 (`/meetupper cancel`): 対象と影響を表示し、確認後にCANCELLEDへ変更して参加者へ通知する。Public MeetUpの募集スレッドもロック・クローズする。
- 開始時刻を過ぎた Public MeetUp は、次回の定期処理（約30秒以内）で募集スレッドを自動的にロック・クローズする。
- 初期化 (`/meetupper init`): 作成・再利用するチャンネルを表示し、確認後に実行する。実行できるのはサーバー管理者だけ。

## 画面間リンク

他機能からも次の固定カスタムIDで画面を開ける。IDの `<meetupId>` は対象MeetUpのIDに置き換える。

| 遷移先 | カスタムID |
| --- | --- |
| 詳細 | `browse:show:<meetupId>` |
| 編集ハブ | `edit:open:<meetupId>` |
| 招待 | `people:invite-open:<meetupId>` |
| キック | `people:kick-open:<meetupId>` |
| 共同主催者 | `people:cohost-open:<meetupId>` |
| 主催者変更 | `people:host-open:<meetupId>` |
| 集合情報 | `ops:info-open:<meetupId>` |
| 退出 | `ops:leave-open:<meetupId>` |
| アーカイブ | `ops:archive-open:<meetupId>` |
| 中止 | `ops:cancel-open:<meetupId>` |
| リマインダー | `reminder:open:<meetupId>` |
| 参加 | `apply:start:<meetupId>` |

カスタムIDの名前空間は、作成 `create:`、一覧・詳細・参加 `browse:`、編集 `edit:`、招待・キック・共同主催者・主催者 `people:`、init・集合情報・退出・アーカイブ・中止 `ops:`、リマインダー `reminder:`、招待回答 `invite:`、チャンネル削除復旧 `recover:`。各機能は自分の名前空間を使う。

## リマインダー設定画面

`/meetupper reminder` は ephemeral の設定画面を開く。主催者・共同主催者だけが操作でき、参加確定者は開けない。

- 自動通知のON/OFF（ONは1〜5件、OFFなら0件も可。最後の1件を削除するにはOFFにする）
- 選択式（7日前/3日前/1日前/12時間前/6時間前/3時間前/1時間前/30分前/10分前）と自由設定（日・時間・分、最短1分前）の追加。同じ時間差は1件に統合される
- 設定済み通知時刻の変更・削除
- 現在の通知予定時刻と送信状況
- 保存・キャンセル・履歴（90日分、新しい順、ページ切り替え、状態・理由・日時変更前後の基準日時）

編集内容は「保存」を押すまでDBに反映しない。「キャンセル」で破棄する。複数人が同時に編集した場合は、保存時に設定バージョンを確認し、古いバージョンからの保存を拒否して再読み込みを促す。通知基準は集合時間が優先で、未設定なら開催日時。

## ボタン操作（募集・招待・承認）

| 場所 | ボタン | 動作 |
| --- | --- | --- |
| 募集フォーラムの投稿 | 参加申請 | Public MeetUpへ参加申請する |
| 参加申請の通知 | 承認 / 却下 | 主催者・共同主催者が申請を裁く |
| 参加申請の通知（投票制） | 賛成票 | 参加確定者が投票する（必要票数に到達すると承認） |
| 招待 DM / 招待スレッド | 参加する / 参加しない | 招待に回答する（回答後に一時スレッドを削除） |
| 参加者からの招待申請 | 承認 / 却下 | 主催者・共同主催者が承認し、DM を送る |
| アーカイブ・中止の確認 | 実行する / キャンセル | 誤操作を防ぐ確認 |
| チャンネル削除後の通知 | MeetUpを中止する / ACTIVE を維持する | 削除された専用チャンネルの再作成後に選ぶ |

## 参加者投票の注意

参加者投票は Public MeetUpでのみ使う。投票できるのは参加確定者だけなので、最初の参加確定者は主催者・共同主催者が `/meetupper invite` で招待して用意する。必要票数は作成モーダルでは選ばず、初期値1から `/meetupper edit` で設定する。承認済み参加者数を超える票数を設定すると承認できない。

## 参加状態

`INVITED`（招待中）、`APPLIED`（申請中）、`APPROVED`（承認済み）、`DECLINED`（辞退）、`REJECTED`（却下）、`CANCELLED`（キャンセル）、`KICKED`（退出）。

専用チャンネルを閲覧できるのは、主催者・共同主催者・`APPROVED` の参加者・Bot のみ。

## 廃止した引数

スラッシュコマンドの `user` / `action` / 各設定フィールド（`name`、`start`、`mode`、`capacity`、`approval`、`event`、`required-votes`、`reminder` など）の引数は削除した。コマンド引数は `[meetup]` だけであり、設定は作成・編集・各操作の画面から行う。
